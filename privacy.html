Privacy policy

Last updated: 11 November 2026

The "Grandpa What If" upload tool is a private tool used only by the owner of the Grandpa What If YouTube channel. It is not offered to the public.

What the tool accesses

With the channel owner's permission (Google sign-in), the tool uses the YouTube Data API and YouTube Analytics API to upload videos and thumbnails to the owner's channel, read the channel's video statistics and public comments, and post replies as the channel.

How data is used and stored

All data stays on the channel owner's own computer. It is used only to manage and improve the channel. Nothing is sold, shared with third parties or used for advertising. Sign-in tokens are stored locally and can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions: through the contact details on the Grandpa What If YouTube channel.
